# VISION

Capuchinho Verde é um tema WordPress moderno derivado do tema Cafeteria, focado em performance, acessibilidade e editor de blocos.

**Problema:** Temas antigos como Cafeteria v1.7 não são compatíveis com WordPress 6.x e PHP 8.x, usam funções obsoletas e bloqueiam adoção do Gutenberg.

**Solução:** Port completo para arquitetura block-first, removendo código legado, adicionando `theme.json`, `add_theme_support('title-tag')`, e práticas AES.

**Valor:** Tema seguro, rápido e mantível para cafeterias, restaurantes e pequenos negócios.
