# REQUIREMENTS

## Funcionais
- Suporte a WordPress 6.0+ e PHP 7.4+
- Compatível com Gutenberg/block editor
- Tema responsivo com viewport meta
- Suporte a menus, logo, custom header/background
- Compatibilidade WooCommerce básica
- Internacionalização

## Não funcionais
- Sem funções obsoletas (query_posts, wp_title, create_function)
- HTTPS only (fonts via https)
- Acessibilidade WCAG 2.1 AA
- Código PSR-12 compatível
- Documentação AES completa

## Restrições
- Não herdar código Aletheme legado
- Manter identidade visual inspirada em Cafeteria
